# Dust extraction

Printable fittings for the shop's dust extraction — hoses, cuffs and adapters.
Separate from the mill's dust shoe, which is in `cad/dust-shoe/`.

3MF rather than STL, so each carries its own print settings.

| File | What |
|---|---|
| `2in-cuff.3mf` | 2 inch hose cuff |
| `2in-to-4in-adapter.3mf` | 2 to 4 inch step |
| `4in-coupler.3mf` | 4 inch coupler |
| `ryobi-cuff.3mf` | cuff for the Ryobi port |
| `ryobi-mitre-saw-hose-adapter.3mf` | mitre saw dust port adapter |
| `solid-brush.3mf` | solid brush |
| `body36.3mf` | unidentified — a Fusion body number rather than a name, and only 1.7 KB |

Every file was checked as a valid 3MF before committing: zip container, model
part present, CRCs intact.

**Two of these may belong with the dust shoe instead.** `solid-brush.3mf` could
be the shoe's brush rather than an extraction fitting, and `body36.3mf` is
unidentified. They were moved here with the rest; move them back if that is
wrong.
